# 差速驱动机器人路径跟踪控制器（Pure Pursuit / Stanley）

给定一条参考路径与机器人当前位姿，计算跟踪该路径所需的转向控制量，
并检测控制器在不同路径曲率、不同参数配置下的稳定性。一次仿真结束后生成
**单一自包含静态 HTML 报告**，可逐帧回放运动过程并查看横向误差曲线。

- 仅依赖 Go 标准库（`math`、`encoding/json`、`embed` 等），无第三方数学库。
- 报告为单个 HTML 文件：数据与逻辑全部内嵌，不启动任何服务，
  前端仅用原生 HTML/CSS/JavaScript 与 Canvas 2D，无任何框架或图形库。

## 构建与运行

```bash
go test ./...          # 运行全部自动化测试
go run . -o report.html   # 跑 9 个内置场景并生成报告
# 直接用浏览器打开 report.html 即可，无需服务器
```

命令行会打印每个场景的收敛/发散判定摘要。报告中可：

- 下拉切换场景，空格播放/暂停，←/→ 逐帧，Home/End 跳到首尾帧；
- 俯视图查看参考路径、实际轨迹、机器人航向、前视点（PP）/切点（Stanley）；
- 右侧查看横向误差 e(t) 曲线，拖动曲线可跳转；失稳场景用红色竖线与
  阴影标出**发散起始时间步**，失控段轨迹以红色重描。

## 运动学模型与输出

差速驱动按 unicycle（单轮）运动学建模：

```
ẋ = v·cosθ,   ẏ = v·sinθ,   θ̇ = ω
```

仿真中前进速度 v 取恒定正值，两个控制器的输出都是**角速度指令 ω**（rad/s），
即差速底盘左右轮速差所对应的转向控制量。时间积分用欧拉法，dt = 0.05 s
（失稳复现场景用更大的 dt 暴露离散化问题）。

横向误差的符号约定（两种控制器、检测器、HTML 图中完全一致）：

```
E = t × (q − x)    （二维标量叉积）
```

t 为路径切向单位向量，q 为最近投影点，x 为机器人位置。
**路径位于机器人左侧时 E>0**；机器人偏到路径左侧时 E<0。

## Pure Pursuit 几何原理与实现要点

### 几何原理

在机器人前方沿路径取一个前视点 g（弧长距离约为前视距离 Ld），令机器人航向
对准 g。设机器人到 g 的方位角偏差为 α，由弦切几何，驶过该弦所需的曲率为

```
κ = 2·sin(α) / Ld,    ω = v·κ = 2·v·sin(α) / Ld
```

它等价于单车模型前轮转角 δ = atan(2L·sinα/Ld) 经 ω = v·tanδ/L 的映射。
控制器是对曲率的比例跟踪，路径在左（α>0）时给正 ω（左转），物理方向自洽。

### 前视点选取的三个关键处理

1. **沿弧搜索"第一个圆交点"，而非全局距离最优点。**
   前视点严格定义为：以机器人为圆心、Ld 为半径的圆，与路径在锚点之后的
   **第一个**交点（每段解一元二次方程，只接受段内参数 t∈[0,1] 的根）。
   在自交叉路径上，第二枝往往也与圆相交；若全局取"半径误差最小"的点，
   锚点会跨枝跳变，甚至直接锁到终点造成转向突变。

2. **有记忆的单调锚点 + 有限回扫窗口。**
   控制器记住上一帧前视点弧长 sGoal，每帧从 `sGoal − Backtrack` 起重新找
   第一个交点。回扫量必须大于单步位移 v·dt（机器人一步内可能越过旧锚点，
   交点短暂落在其后方），又要明显小于 Ld（默认 0.4·Ld）。这样临近自交叉点
   时，圆与"来路"尾段的交点落在回扫窗口之外（该交点在旧锚点后方超过
   Backtrack），扫描自然越过交叉点、落到"去路"首段；而来路尾段延长线上的
   虚假交点因 t>1 被拒绝。首帧锚点强制为路径起点（自交叉点处全局最近投影
   无法区分去路与另一圈的末端）。

3. **路径终点附近不外推。**
   仅当"沿弧剩余长度 ≤ Ld"且"终点空间距离 ≤ Ld"两者同时成立时才锁定终点
   （第一个条件防止在自交叉路径的中间交叉点提前锁定）。锁定瞬间圆与路径的
   最后一个交点正与终点重合，目标点不跳变；机器人越过终点后也不会把圆在
   来路上的进入点误当新目标反向打舵。

### 参数选择（Ld）

```
Ld = clamp(Kf·v, LdMin, LdMax)
```

- Ld **大**：平滑、抗噪，但转弯切角（cutting corner）大、横向误差大；
- Ld **小**：贴路径紧，但等效增益 2v/Ld 大，离散控制下容易振荡失稳
  （本仓库失稳案例 1：v=2.5、dt=0.15、Ld=0.06 即发散）；
- 经验区间 Ld ≈ (2~5)·v·dt 以上；工程上常取 Kf 使 Ld 随速度增大，
  低速由 LdMin 兜底（避免 Ld→0 增益无穷大），高速由 LdMax 限制弯道看穿。

## Stanley 几何原理与实现要点

### 几何原理

Stanley（Stanford 路径跟踪）以前轮转角为输出，由两项相加：

```
δ = θe + atan(k·E / (v + ks))
ω = (v/L)·tanδ
```

- **航向误差项** θe = wrapPi(φ_path − θ)：最近切点处路径切向与机器人
  航向之差，负责对齐方向；
- **横向误差项** atan(kE/(v+ks))：按横向偏差修正方向，离路径越远打舵越多，
  天然有界（±π/2），不会因大偏差给无限指令；
- ks 为软ening 速度：低速时分母不至于趋零，抑制原地抖舵；
- L 为等效轴距，把单车转角映射为差速车的角速度。|δ| 接近 π/2 时 tan 会
  数值发散，代码把 δ 钳到 ±(π/2−0.05) 再映射，钳制在边界处 C0 连续、
  符号与 δ 一致，输出始终有限。

### 角度环绕（−π 到 π 边界）

θe **必须**经过 `wrapPi` 归一化到 (−π, π]。在整圆跟踪中，路径切向与机器人
航向在最左点同时从 +π 翻到 −π，直接相减会得到约 ±2π 的假航向误差，使
δ 与 ω 瞬间跳变（错误地向反方向猛打舵）。归一化后该差值为 0，控制量连续。
本仓库所有角度差一律走 `wrapPi`，不允许直接对两个 atan2 结果做差。

### 横向误差过切点的符号一致性

E 由叉积 `t × (q−x)` 直接给出，**全程不调用 atan2、不依赖机器人航向**。
机器人从路径右侧横移越过切点到左侧时，E 从正连续穿过 0 变负，
`atan(kE/(v+ks))` 随之平滑反向——右转越过切点后自动变成左转，始终把机器人
拉回路径，不会出现"越过切点符号翻转→反向推离"的错误。

### 参数选择

- **k（横向增益，单位 1/s）**：越大回位越快，但过大使横向项在小误差时也
  频繁饱和、与航向项争抢，离散下振荡；典型 0.5~2。
  失稳案例 2 用 v=2、dt=0.25、k=3 且 L=0.03 制造发散。
- **ks（软ening 速度，m/s）**：按最低运行速度取 0.05~0.3，仅影响低速。
- **L（等效轴距，m）**：δ→ω 的映射增益为 v/L；L 越小同样转角产生越大的
  角速度，过小会显著降低离散稳定裕度。
- 离散稳定裕度还取决于 v·dt/L 与 k·dt：采样越粗、速度越高，越要减小 k、
  增大 L，这与 Ackermann 实车标定经验一致。

## 失稳判据与发散时间步定位

检测器输入横向误差序列 e[0..N] 与采样周期 dt，输出是否发散、起始帧/时间、
峰值与末值。两条判据，取最先触发者（`stability.go`）：

1. **硬限**：|e| 首次超过 hardLimit（默认 3 m）即判发散。物理失稳（PP 的
   Ld 过小、Stanley 的 L 过小/k 过大）多为强指数发散，通常先触发本条。
2. **包络连续增长**：跳过 1 s 的起振保护（初始误差可能本身就大），把序列
   按 2 s 分块取每块 |e| 的最大值；若**仿真末端**存在连续 ≥3 个块以
   ×1.2 以上递增、末块达到全程最大值的 95% 且高于 0.25 m 噪声底，则判发散。
   "扩张必须在末端仍在进行"使先扩张后重新收敛/走平的**有界振荡**不被误判。

发散起始时间步定位：

- 硬限触发：即首次越限的那一帧；
- 包络触发：扩张段第一个块内，误差**首次超过扩张前包络水平**的那一帧
  （即突破原有振荡包络的精确时刻）。

末尾不足一个整块长度的截断块不参与包络计算（其包络天然偏低，会错误打断
末端扩张链）。测试中同时用合成的"慢指数发散（峰值不触硬限）""有界振荡"
"指数收敛"三类序列验证判据二与反例。
